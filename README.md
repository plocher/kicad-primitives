# kicad-primitives

Stand-alone Python package (`kicad_primitives`) for reading, editing, and writing KiCad 10 projects and libraries — consolidating KiCad handling that today lives across jBOM, kproj, kDoctor, EagleLib2KiCad, FieldUnit-Subdivision, and Railroad.

**Status:** founding survey + wayfinder map; package surface not yet shipped.

## Start here

- [`AGENTS.md`](AGENTS.md) — working agreements and API area list
- [`docs/kicad-services-survey-2026-10-12.md`](docs/kicad-services-survey-2026-10-12.md) — inventory, overlaps, gaps, options
- GitHub Issues — wayfinder map for the stand-alone package effort

## Non-goals (until a consumer asks)

PCB editing, 3D models.
