| [0009-primitives-not-an-executive.md](0009-primitives-not-an-executive.md) | Accepted; save/close/save-as splits refined by 0011 (proposed) | Some operations bundle several capabilities and hide the policy (save = guard + verify + write + ZIP). Proposal: one-job primitives with file-integrity checks inside; policy (verification, history, ERC, discovery) lives in an explicit, tested `recipes` layer built only from public primitives. Verification is a client before/after netlist compare; the package does not predict or excuse expected changes. One lifecycle for every artifact (open, read, modify, validate, write, close) with a public `validate()`, a flag-based `is_modified`, and write promises (no silent overwrite, no partial file). Peer locks are a query, not a write guard. Footprint libraries are a directory level plus per-file `Footprint` artifacts, with immediate delete and rename. Lists composites to split and the rename-repoint recipe follow-up. |
| [0011-schematic-document-model-save-and-revert.md](0011-schematic-document-model-save-and-revert.md) | Proposed | Package nouns contradicted KiCad (the `Schematic` class was one file), and save bundled locks, `kicad-cli`, and ZIPs. Proposal: `SheetFile` / `SheetSymbol` / `SheetInstance` / `Schematic` (a set of sheet trees). `Schematic.save()` writes only changed sheets, with classified failure handling. Scopes close with `on_close`; documents and items `save()` or `revert()`. `backup()` archives disk state with explicit arguments. `save_as` is project-only. No recipes yet. ADR 0010 is reserved for #78. |
